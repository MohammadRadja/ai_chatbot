# UI Primitive Agent Guide

Scope: reusable visual primitives such as `Button` and `Badge`.

- Keep primitives small, typed, composable, and accessible.
- Preserve variants, focus rings, disabled states, and the existing token palette.
- Do not add feature-specific data fetching or business logic here.
- Prefer `cn` for class composition and keep the local shadcn/ui-style API stable.
