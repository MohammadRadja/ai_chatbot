# Public asset instructions

- Keep only intentional, production-ready static assets here.
- Branding assets must match `app/icon.svg`, `src/components/brand-mark.tsx`, and the design tokens in `docs/DESIGN.md`.
- Do not add framework placeholders, generated build output, secrets, or user-uploaded content without an explicit storage/security design.
- Keep filenames stable when referenced by `app/layout.tsx` metadata.
